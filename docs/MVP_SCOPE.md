# MVP 범위

## 이번 단계

- 현재 폴더 및 하위 폴더의 자료를 조사한다.
- 제공된 CSV를 `data/private/input`에 복사해 원본과 분리된 읽기 전용 입력본으로 사용한다.
- CSV의 구조, 품질, `company_id` 연결을 감사하고 결과를 문서화한다.
- 향후 화면·DB·PDF 처리·내보내기 구현을 위한 설계만 작성한다.

## 제외 범위

Streamlit 화면, 업체 검색 화면, 지도점검 직접 등록, 데이터 수정·삭제, Supabase 연결 또는 SQL 실행, OpenAI API, PDF 업로드·분석, 파일 다운로드, 벡터 RAG, 위험도·우선순위·지도 기능, 공개 배포, Git 초기화·commit·push는 구현하지 않는다.

## 검색 원칙(향후 구현)

업체 마스터에 실제 존재하는 업체명, 업체명 별칭, 허가번호, 주소·지역, 대표자, 업종, 영업상태 등만 전체 검색과 항목 필터 대상으로 삼는다. 자유 메모, 내부 검토 메모, 개인정보 성격의 값은 전체 검색에서 제외한다. `company_id` 정확 일치가 최우선이며, 허가번호 정확 일치, 정규화된 업체명과 주소의 동시 일치 순으로 보조한다. 이름이 비슷하다는 이유만으로 자동 연결하지 않는다.
