## 프로젝트 폴더

- `data/private/input`: 보존용 CSV 복사본(Git 제외)
- `data/private/runtime`: 향후 등록·런타임 데이터(Git 제외)
- `data/sample`: 비식별 예제 데이터 예정
- `docs`: 범위·설계·감사 문서
- `reports`: 감사 결과
- `scripts`: 데이터 감사 스크립트
- `src`, `pages`, `tests`, `supabase`: 향후 단계용 빈 구조
