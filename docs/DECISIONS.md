# 결정 기록

| 항목 | 결정 | 근거 |
| --- | --- | --- |
| 입력 데이터 | 로컬 CSV 우선 | 초기 단계에서 외부 DB 연결 없이 구조와 품질을 검증한다. |
| 원본 보존 | 원본 폴더·ZIP·XLSX는 변경하지 않음 | 업무 자료의 추적성과 재현성을 보호한다. |
| 작업용 입력 | `data/private/input`에 CSV 복사본 사용 | 원본과 런타임 데이터를 분리한다. |
| 연결 키 | `company_id` 우선 | 업체명 변경·유사명에 따른 오연결을 방지한다. |
| 점검·처분 | 별도 테이블·별도 이력 | 행정처분은 점검과 독립된 검토·확정 절차가 필요하다. |
| PDF 처리 | 설계만 작성 | API·OCR·업로드 기능은 현재 범위 밖이다. |
