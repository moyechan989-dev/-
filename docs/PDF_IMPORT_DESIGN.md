# 출장결과보고서 PDF 가져오기 설계(향후 구현)

초기 지원 대상은 텍스트를 선택·복사할 수 있는 PDF이며, 스캔 PDF와 OCR은 제외한다. 현재는 구현하지 않는다.

1. PDF를 등록하고 `report_imports`에 파일 정보와 추출 상태를 만든다.
2. 추출 텍스트에서 업체 후보와 지도점검 후보를 만든다.
3. 한 업체만 명확할 때만 초안을 제시한다. 여러 업체가 감지되면 자동 등록을 중단하고 사용자에게 알린다.
4. 업체별 분리 등록은 담당자 선택 또는 향후 업체별 초안 분리 기능으로 진행한다.
5. 처분 관련 문구는 상태값과 후보 정보로만 보관하며, 담당자 확인 후에만 처분 이력으로 반영한다.

매칭 우선순위는 `company_id` 정확 일치, 허가번호 정확 일치, 정규화된 업체명과 주소 동시 일치, 등록된 별칭 일치, 담당자 직접 선택 순이다.
