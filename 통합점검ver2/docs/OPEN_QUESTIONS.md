# 확인이 필요한 사항

현재 감사 스크립트가 자동으로 해결하지 않는 항목은 이 문서에 기록한다. 데이터 감사 실행 결과에서 발견된 질문을 아래에 추가한다.

- 업체 마스터에 영업상태·대표자·처리 폐기물 등의 검색 가능 열이 실제로 어떤 이름으로 제공되는지, 화면 구현 전 확정이 필요하다.
- 직원 별칭의 유효성 여부를 대조할 기준 명부는 현재 CSV에 없으므로, 담당자·검사자 별칭 검증 기준을 정해야 한다.
- `07_matching_review.csv`의 `new_company` 매칭 방식이 기존 마스터에 신규 업체를 추가했다는 의미인지, 원천 자료 연결 결과인지 업무 정의 확인이 필요하다.
- 원본 자료와 시제품 CSV가 혼재할 가능성, 그리고 실제 운영에서 어느 파일을 기준으로 갱신할지 확인이 필요하다.
